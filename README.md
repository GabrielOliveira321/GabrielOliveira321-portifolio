## 📋 Sobre

Portfólio profissional desenvolvido para apresentar minhas competências, experiências e projetos como desenvolvedor FullStack. O site conta com design moderno, animações fluidas, modo escuro e total responsividade.

## ✨ Funcionalidades

- **Design responsivo** — Funciona em desktop, tablet e mobile
- **Modo escuro** — Tema escuro com transições suaves
- **Animações** — Micro-interações e transições com Framer Motion
- **Seções completas** — Hero, Sobre, Experiências, Skills, Projetos, Contato
- **Performance** — Build otimizado com Vite

## 🛠️ Stack Tecnológica

| Categoria | Tecnologias |
|-----------|------------|
| **Frontend** | React 19, TypeScript 6, HTML5, CSS3 |
| **Animações** | Framer Motion |
| **Ícones** | React Icons |
| **Build** | Vite 8 |
| **Linting** | ESLint 10 |

## 🚀 Como executar

```bash
# Clonar o repositório
git clone https://github.com/GabrielOliveira321/portfolio.git

# Entrar na pasta
cd portfolio

# Instalar dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev
```

O site estará disponível em `http://localhost:5173`.
